## 3. Required Manual Actions

### Render Backend
1. Go to https://dashboard.render.com
2. Create new Web Service from GitHub repo `GhariebML/NORAY`
3. Set environment variables:
   - `ENVIRONMENT=production`
   - `MIMIO_API_KEY=<YOUR_MIMIO_API_KEY>`
   - `MIMIO_BASE_URL=https://api.xiaomimimo.com/v1`
   - `MIMIO_MODEL=mimo-v2.5-pro`
   - `AI_PROVIDER=auto`
   - `EMBEDDINGS_PROVIDER=local`
   - `EMBEDDINGS_MODEL=all-MiniLM-L6-v2`
   - `ALLOW_OFFLINE=true`
   - `ALLOWED_ORIGINS=https://noray-frontend.vercel.app,http://localhost:3000`
   - `GOOGLE_API_KEY=<YOUR_GOOGLE_API_KEY>`
   - `OPENROUTER_API_KEY=<YOUR_OPENROUTER_API_KEY>`
   - `DEEPSEEK_API_KEY=<YOUR_DEEPSEEK_API_KEY>`
   - `TOGETHER_API_KEY=<YOUR_TOGETHER_API_KEY>`
4. Health check path: `/health`
5. Start command: `uvicorn noray.api.app:app --host 0.0.0.0 --port $PORT`

### Vercel Frontend
1. Go to https://vercel.com/dashboard
2. Project Settings → Environment Variables
3. Add: `NEXT_PUBLIC_API_URL=https://noray-backend.onrender.com`
4. Set production domain alias (Settings → Domains)

### Streamlit Cloud
1. Go to https://share.streamlit.io
2. Deploy from `academic_demo/streamlit_app.py`
3. Add secrets:
   ```toml
   NORAY_API_URL = "https://noray-backend.onrender.com"
   MIMIO_API_KEY = "<YOUR_MIMIO_API_KEY>"
   MIMIO_BASE_URL = "https://api.xiaomimimo.com/v1"
   MIMIO_MODEL = "mimo-v2.5-pro"
   ```
