# Comprehensive System Features Overview

NORAY provides a unified AI Operating System tailored for career optimization, academic research, and knowledge management.

---

## 🌟 Core System Modules

1. **Global Knowledge System**: Upload files on any page to automatically extract, chunk, embed, and store knowledge across vector stores and BM25 indices.
2. **AI Workspace Canvas**: Chat interface with streaming responses, source citation cards, confidence scores, and reasoning traces.
3. **Career Command Center & ATS Evaluator**: Analyzes resume fit (0-100%) against job descriptions and generates tailored LaTeX CVs and cover letters.
4. **PhD & Scholarship Search Engine**: Multi-portal scraper for DAAD, Chevening, Fulbright, and Erasmus Mundus with eligibility scoring.
5. **Memory Explorer & Knowledge Graph**: Visualizes entity relationships and RAG context paths using interactive node graphs.
6. **Telemetry & System Diagnostics**: Monitors real-time backend ping latency, active LLM gateway candidates, vector database dimensions, and hardware status.
