## 🎙️ Slide 1: Introduction to NORAY
- "Good morning. NORAY is an Enterprise AI Operating System designed to address context fragmentation across job search, academic research, and document management."

## 🎙️ Slide 2: The Core Innovation — Dual RAG Engine
- "Unlike standard chatbots, NORAY fuses dense vector searches (Qdrant) with sparse keyword searches (BM25) using Reciprocal Rank Fusion (RRF)."

## 🎙️ Slide 3: Resilience & Dual Deployment Strategy
- "We built a dual-deployment model: an enterprise Next.js/FastAPI stack containerized in Docker, and a lightweight Streamlit app for immediate course evaluation."
