# NORAY OS v1.0.0 — Release Candidate 1 (RC1)

We are thrilled to announce the official **v1.0.0 Release Candidate** of the **NORAY AI Operating System**!

---

## 🌟 Highlights & Core Features

- **Hybrid RAG Core**: Fuses dense Qdrant vector retrieval with sparse BM25 keyword matching via Reciprocal Rank Fusion (RRF).
- **Dual-Deployment Targets**: Enterprise Next.js/FastAPI stack for cloud hosting + lightweight Streamlit dashboard for academic evaluation.
- **Provider Gateway Priority**: Automatic failover ordering: 1. Gemini, 2. OpenRouter, 3. Together, 4. DeepSeek, 5. Gemma Local, 6. Qwen Coder Local.
- **Academic Submission Package**: 12 complete submission manuals & walkthrough scripts inside `SUBMISSION_PACKAGE/`.
- **Complete Test Coverage**: 511 passed unit and integration tests across backend modules.
