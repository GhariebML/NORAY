# Security Policy

## Supported Versions

Only the latest release version of NORAY is supported for security updates:

| Version | Supported |
| --- | --- |
| v1.0.x | :white_check_mark: |
| < v1.0 | :x: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it immediately to avoid public disclosure.

1. **Email Reports**: Send a detailed description of the vulnerability to the project maintainers.
2. **Details to Include**:
   - Step-by-step instructions to reproduce the issue.
   - Potential impact (e.g., privilege escalation, data leakage, RAG injection).
   - Any proposed patch/fix if available.

We will acknowledge your report within 48 hours and work to provide a patch promptly.
